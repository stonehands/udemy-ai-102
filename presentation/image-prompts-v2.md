# AIプロジェクトのリアル — Images 2.0 プロンプト集

15スライド構成。共通プロンプトを各スライドプロンプトの末尾に追加して使用。

---

## 共通プロンプト（全スライドに付加）

```
Create a premium executive presentation slide.

Style: Baycurrent Consulting, McKinsey, BCG
Audience: Executive management, Enterprise transformation leaders, AI project managers
Canvas: 16:9 presentation slide

Design principles:
- Message-driven, one slide one message
- Large whitespace, simple and elegant
- Structured consulting-style layout
- Premium corporate quality

Visual tone:
- Enterprise AI, Japanese enterprise transformation
- Professional, thought-provoking
- Not flashy, not startup style, not marketing poster style

Color palette:
- White background (except title slide)
- Navy blue primary color
- Blue accent color
- Light gray secondary color

Typography: Modern sans-serif, large title, strong visual hierarchy, minimal text
Icons: Thin line icons, consistent corporate style
Graphics: Consulting-style diagrams, executive-friendly visuals, clean infographics
Layout: Large title top-left, main visual center, supporting content below, generous margins

Avoid: Stock photos, people posing, sunset scenes, marketing visuals,
futuristic sci-fi effects, 3D rendering, dark backgrounds (except title slide)
```

## 使用方法

1. 使いたいスライドの個別プロンプトをコピー
2. 末尾に共通プロンプトを貼り付け
3. Images 2.0 / DALL-E 3 / Midjourney v6 で生成
4. 推奨解像度：**1920×1080**（16:9）
